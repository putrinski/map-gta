# 🗺️ Leonida Recon HD — Mapa Personal de GTA VI (Sin Spoilers)

Mapa interactivo en alta resolución de **Leonida (GTA VI)** diseñado para llevar tu propia exploración sin spoilers, con **niebla difuminada interactiva** y **marcadores personalizados ilimitados con notas de contexto**.

Todo funciona en un único archivo `index.html` sin necesidad de servidores ni bases de datos: tu progreso se guarda automáticamente en tu navegador y puedes exportarlo o compartirlo en `.json`.

---

## ✨ Características principales

- **🔍 Zoom HD sin pérdida de nitidez:** Carga teselas limpias de Leonida (sin iconos ni spoilers) con soporte para **Modo Día** (`day-v2`) y **Modo Noche** (`night-v3`).
- **🏠 Resaltar Interiores:** Botón rápido que ajusta el contraste y la saturación del mapa para distinguir fácilmente los edificios en tono azul oscuro con interior accesible.
- **🌫️ Niebla de Guerra Difuminada (Sin Spoilers):** Desenfoque gaussiano real que oculta detalles y nombres pero deja entrever la silueta de islas, costas y autopistas para guiarte.
  - Tres modos: **Difuminado Suave**, **Difuminado Intenso** y **Sin Difuminado**.
  - Pinceles **Descubrir** y **Cubrir** de tamaño ajustable para ir revelando tu mapa conforme exploras.
- **📍 Marcadores con contexto y seguimiento de interiores:**
  - **Interior Pendiente (Volver):** Pin ámbar con pulso visual para marcar edificios donde quedó un puzle, caja fuerte o tarea pendiente.
  - **Interior Completado:** Pin verde esmeralda con cambio de estado en un solo clic tanto desde el mapa como desde el panel lateral.
  - Categorías adicionales: *Puzle / Código*, *Botín / Coleccionable*, *Misterio / Easter Egg*, *Vehículo / Garaje*, *Peligro / Banda* y *Punto de Interés*.
  - Buscador por texto, filtros por categoría y eliminación directa desde la barra lateral.
- **💾 Guardado local y copias de seguridad:** Persistencia automática en `localStorage` + botones para **Exportar / Importar `.json`** y compartir tu mapa con amigos.

---

## ⌨️ Controles y atajos rápidos

| Atajo | Acción |
| :--- | :--- |
| `1` | Herramienta **Navegar** (mover y hacer zoom) |
| `2` | Herramienta **Nuevo Pin** |
| `3` | Pincel **Descubrir** (borrar difuminado) |
| `4` | Pincel **Cubrir** (volver a difuminar) |
| `[` / `]` | Disminuir / aumentar el tamaño del pincel |
| `Shift + Clic` | Crear un pin rápido en cualquier punto |
| `Clic derecho` *(en modo pintura)* | Arrastrar y mover el mapa sin cambiar de herramienta |
| `Esc` | Cerrar ventanas modales |
